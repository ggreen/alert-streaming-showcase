Alert Dispatcher Help

        


        

            
This tool allows Security Engineers and Developers to construct and test real-time security alerts sent directly to endpoint APIs.

            
    
                
  • cURL Mirroring: Generates formatted cURL identical to your server execution string.
    • 
                
  • Severity Badges: Standardized visual hierarchy (Low, Medium, High, Critical).
    • 
                
  • Local Testing: If target server http://localhost:6661 is offline, direct standard CORS browser errors will be handled gracefully in the execution log.
